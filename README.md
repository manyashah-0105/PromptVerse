# PromptVerse (from Figma "Prompt-verse design")
Open `index.html` (or run `python3 -m http.server`). No build step, no dependencies except the Inter font from Google Fonts.

index.html · categories.html · about.html
css/styles.css · js/data.js (category text, add prompts here) · js/components.js (header, CTA, idea card, dialogs, icons) · js/app.js (behaviour)
assets/images/categories/*.svg (card pictures – replace with your own, same file names or edit data.js)
assets/images/tools/*.svg (ChatGPT/Gemini/Canva/MidJourney badges – replace with your Figma exports)
